# FailForward-AI
Every Failure Teaches. Every Lesson Empowers.

FailForward AI is an AI-powered anonymous platform that helps users learn from their failures. Users can share their failure experiences without revealing their identity, while AI analyzes the possible causes, emotions, and patterns and provides personalized recommendations for improvement. The platform also connects users with others who have faced similar experiences, creating a supportive community for learning, reflection, and growth.

Tech Stack: Python, FastAPI, Firebase Firestore, Gemini AI, NLP, HTML, CSS, JavaScript.
